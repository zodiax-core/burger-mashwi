# Burger Mashwi Arabic Home/Menu

## Build
- Replace the blank home page with one polished, long Arabic RTL restaurant menu.
- Follow the supplied reference composition: compact header, promotional food banner, centered search, repeated category banners and compact product grids, then a concise footer.
- Use only categories represented in the final two menu images: burgers, burger meals, wraps, fries, and fried sides.

## Visual direction
- Warm cream page, deep food-brand green, white cards, charcoal text, and restrained warm accents.
- Tajawal Arabic typography with compact, practical hierarchy and prominent transparent food cutouts.
- Create a cohesive set of burger, wrap, fries, and fried-side cutout assets for the advertising banner, category banners, and products.

## Interaction
- Search filters products instantly.
- Add controls morph smoothly between “add” and quantity stepper states.
- Cart count and total update immediately; the header cart opens a working order drawer.
- Use restrained spring entrances and viewport reveals, with reduced-motion support.

## Responsive behavior
- Spacious centered desktop grid with 3–4 compact cards per row.
- Intentionally compact mobile header, banners, cards, and a persistent cart shortcut.

## Technical details
- Keep menu/category data separate from reusable React components.
- Use semantic Tailwind design tokens in the global stylesheet and Motion for React for state and reveal animation.
- Add complete home-page metadata and verify the result at desktop and mobile sizes.

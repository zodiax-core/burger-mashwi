# Burger Mashwi Delight

Build ONLY the main Home/Menu page for a restaurant website called:

BURGER MASHWI

IMPORTANT:

I am attaching reference screenshots. Use them as the PRIMARY visual inspiration for the website structure, composition, spacing, product presentation, section headers, cards, typography hierarchy, and overall visual rhythm.

DO NOT make a generic AI-generated restaurant website.

DO NOT redesign this into a modern SaaS-style website.

DO NOT use glassmorphism.

DO NOT use gradients everywhere.

DO NOT use glowing effects.

DO NOT use excessive shadows.

DO NOT use floating 3D UI.

DO NOT use random decorative icons.

DO NOT make it futuristic.

DO NOT make it look like an AI website template.

The website should feel like a REAL, professionally designed Pakistani/Arab restaurant ordering website.

==================================================

CORE DESIGN DIRECTION

==================================================

Brand:

BURGER MASHWI

Primary visual identity:

- Green is the primary brand color.

- Use a deep/dark food-brand green for important elements.

- Supporting colors can include cream/off-white, white, black/dark charcoal, and small controlled warm food tones.

- DO NOT make the entire website black.

- The background should primarily be a warm light/cream/off-white tone similar to the reference screenshots.

- Green should immediately communicate the Burger Mashwi brand.

The result must be:

- vibrant

- eye-catching

- clean

- minimal

- premium

- food-focused

- highly readable

- practical

- fast to understand

- extremely easy to order from

The screenshots show a long menu-style homepage with:

- header

- large promotional hero

- search

- category/product sections

- large visual category banners

- food products displayed underneath

- footer

Follow this overall structure.

==================================================

LANGUAGE / RTL

==================================================

The DEFAULT website language must be ARABIC.

Use proper RTL layout throughout the entire interface.

Arabic should NOT feel like translated English.

Use a beautiful minimalist modern Arabic font such as:

"Tajawal", "IBM Plex Sans Arabic", or another highly readable modern Arabic UI font.

Prefer:

Tajawal / IBM Plex Sans Arabic

Use proper Arabic typography, spacing and hierarchy.

The website should open in Arabic by default.

All visible navigation, buttons, labels, categories and product information should initially be Arabic placeholder content.

==================================================

HEADER

==================================================

Create a very clean restaurant header inspired by the reference screenshot.

Desktop:

- Burger Mashwi brand/logo on the left/right according to RTL

- minimal navigation

- menu/home navigation

- cart button

- optional language control

- compact header

- no giant navbar

Mobile:

- compact header

- Burger Mashwi branding

- cart button

- hamburger/menu button if needed

The header must remain simple.

Do not overload it with links.

==================================================

HERO SECTION

==================================================

Create a large restaurant promotional hero similar in visual impact to the reference screenshot.

Use:

- rounded large container

- warm/light surrounding background

- strong green Burger Mashwi branding

- high-quality food photography

- large Arabic promotional headline

- short supporting text

- clear CTA

Example placeholder Arabic copy:

"طعم يستاهل التجربة"

"برجر مشوي على أصوله"

CTA:

"اطلب الآن"

BUT:

Do not hard-code this exact copy if better realistic Arabic copy can be used.

The hero should look like an actual restaurant advertisement.

Food photography must be prominent.

IMPORTANT:

Food/product PNG images must have NO background.

Use transparent-background food cutouts wherever possible:

- burgers

- grilled chicken

- fries

- sandwiches

- sauces

etc.

Do not put food products inside ugly square image boxes.

Food should visually sit naturally inside the composition.

==================================================

HERO ANIMATION

==================================================

Animations are VERY IMPORTANT.

The website should feel extremely smooth.

Use Framer Motion or an equivalent animation system.

The hero should have a subtle entrance sequence:

1. background/container appears smoothly

2. typography morphs/fades upward

3. food product images smoothly move into position

4. CTA appears

5. small secondary elements follow

Use smooth spring-based motion.

NO:

- aggressive bouncing

- spinning food

- random floating

- excessive parallax

- flashy transitions

Everything should feel intentional and premium.

==================================================

PRODUCT CARDS

==================================================

Desktop:

- compact cards

- clean spacing

Mobile:

Each card should contain:

Product name in Arabic

Short description

Price in PKR

Add button

Example:

"برجر لحم مشوي مع الجبن والخضار"

"Rs. 799"

Do NOT make giant ecommerce product cards.

==================================================

PRODUCT IMAGE REQUIREMENT

==================================================

THIS IS VERY IMPORTANT:

All food/product images should ideally be transparent-background PNG/WebP cutouts.

NO white square backgrounds around food.

NO random stock-image frames.

NO fake AI-looking food renders.

The food itself should visually sit on the page.

Examples:

- burger cutout

- grilled chicken cutout

- fries cutout

- wings cutout

- drink bottle cutout

- sauce bowl cutout

If temporary placeholder images are needed, structure the code so the image assets can easily be replaced later.

Create a clean central product-image area without forcing a colored rectangular background behind every food item.

==================================================

The UI should provide a subtle visual confirmation.

Do NOT navigate away from the menu.

The customer should be able to continue browsing.

The cart count should update instantly.

Cards can subtly expand when interacted with.

Do not overanimate everything.

==================================================

==================================================

The website should feel exceptionally smooth when scrolling.

Use subtle reveal animations for:

- category banners

- product cards

Elements should appear naturally as they enter the viewport.

Use:

The reference website has a very clean vertical rhythm.

Replicate that feeling.
